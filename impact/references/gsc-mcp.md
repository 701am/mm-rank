# GSC via MCP

When a Google Search Console MCP is connected, MM Rank can read:

- Top queries by clicks and impressions
- Striking-distance queries (position 5-20)
- CTR vs expected by position
- Page-level performance

Paste a CSV export if no MCP is available. The `parse_gsc.py` script handles the standard Search Console export format.

Label all GSC-derived numbers as measured. Do not invent missing data.
