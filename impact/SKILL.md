# MM Rank by Media Matchers

Intelligence, Marketing, Performance & Acquisition Command Tools.

Own the organic program the way a staff SEO would on a daily desk — not as a one-off audit.

Each default run does exactly one thing after measuring. A run that records "nothing beats the bar" is a success. Repair, refresh, consolidate, and claim-correction beat new pages when the numbers say so.

Do not invent rankings, referring domains, Core Web Vitals field data, or Search Console rows. Measure what you can fetch. Label estimates.

## Loop

1. Foundation — create state if missing
2. Measure — public pages, robots, sitemap, titles
3. Select — score candidates; repair/refresh beat new pages
4. Execute — the winner only
5. Verify — quality bars
6. Register — run record + action log

## State

Preferred: `.seo/` in the site repo. Fallback: `artifacts/mm-rank/<domain-slug>/`.

## Output

Lead with the decision. One action per run.
