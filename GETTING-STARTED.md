# Getting Started — MM Rank by Media Matchers

**First site in 15 minutes.**

## 1. Install

```bash
bash install.sh
```

Or copy skill folders to:

| Agent | Destination |
|-------|-------------|
| Claude Code / Cowork | `~/.claude/skills/` |
| OpenCode / OpenWork | `~/.agents/skills/` or `~/.claude/skills/` |
| Grok | `~/.grok/skills/` |

## 2. First run

```
Run MM Rank on example.com
```

The agent creates a vault, reads the public site, and returns the single best next action.

## 3. Daily use

```
Run MM Rank
```

or

```
Best next SEO move on example.com
```

See the root README.md for the full feature list.
