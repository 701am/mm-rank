# SXO

Search experience diagnosis.

## Checks

- Page type vs SERP intent mismatch
- Above-the-fold content vs query
- Internal link context
- CTA placement vs intent

## Output

- Mismatch diagnosis
- Recommended page type or template change
- Exact edits for the highest-leverage section
