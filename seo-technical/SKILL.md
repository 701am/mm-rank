# Technical SEO

## Checks

- Crawlability and indexability
- robots.txt and sitemap
- Security headers
- URL structure
- Mobile readiness
- Performance proxies (TTFB, byte weight)
- Structured data presence
- JS rendering impact

## Output

- Issues by severity
- Smallest correct patch for the worst defect
- Verification test

Do not invent Core Web Vitals field data. Label estimates.
