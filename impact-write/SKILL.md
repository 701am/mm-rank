# MM Rank write

One editorial piece that earns its place.

## Do

2. Check the truth ledger for claims
3. Write the draft in brand voice
4. Humanizer on the output
5. Name the URL, the vital it targets, and the verification test

Do not invent rankings or traffic numbers. One piece per run.
