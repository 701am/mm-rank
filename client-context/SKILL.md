# Client Context

Before doing anything else: check whether a client context file exists for this client.

## Where to find client context

**With memory (vault):**
Read brand, voice, products, competitors, and truth ledger from the site vault.

**Without memory (single session):**
Ask the user: "Before I start, tell me about the client — what they do, who they serve, and what makes them worth covering."

## What client context contains

**Business** — What the business actually does, who it serves, what makes it genuinely different. Every claim must be verifiable.

**Voice** — How the client communicates. Specific enough to use as a yes/no filter for every output.

**Story** — The real founding story. Not the polished version.

**Products** — What is sold, how it works, proof with a number and a source.

**Competitors** — Who else is in the space, what they claim, what they do not.

**Truth ledger** — Only sourced facts. If it is not here, do not put it on a page.

## Output

If context is missing, ask for it. If context exists, use it as the filter for every claim and every piece of copy.
