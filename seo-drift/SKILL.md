# SEO Drift

Baseline + change detection.

## Do

1. Capture current titles, H1s, meta, and key metrics
2. Compare against previous baseline if it exists
3. Flag material changes (title rewrites, content shifts, status changes)
4. Recommend whether the change is intentional or needs review

Label estimates. Do not invent historical data.
