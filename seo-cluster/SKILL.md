# Semantic Topic Clustering

SERP-overlap clustering, not text similarity. Groups keywords by shared top-10 organic results.

Designs hub-and-spoke architecture with internal link rules that MM Rank can later execute via the editorial or programmatic lane.

## Process

1. Expand the seed to 30–50 variants using web search
2. Classify intent. Drop navigational
3. Cluster by SERP overlap: 7–10 shared → same page; 4–6 → same cluster; 2–3 → adjacent; 0–1 → separate
4. Pick the pillar. Build 2–5 clusters, 2–4 spokes each
5. Output architecture + internal link matrix

Do not invent search volume. Label any volume estimates.
