# Full site audit

## Collect

- Homepage, nav, robots.txt, sitemap
- 3-5 key templates (product, category, blog, location, about)
- Titles, H1s, meta, schema presence
- Internal link structure

## Score

- Technical (indexability, robots, sitemap, headers)
- Content (depth, E-E-A-T signals, thin pages)
- Schema (presence and validity)
- AI-search readiness (citability, llms.txt)

## Output

- Scored health summary
- Issues by severity
- 14-day action list vs 90-day list
- Open questions for the user

Do not invent referring domains, traffic, or keyword rankings.
