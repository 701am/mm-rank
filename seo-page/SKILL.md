# Single-page SEO

## On-page checklist

- Title 50–60 characters, unique, primary intent
- Meta description 150–160, not a title echo
- Single clear H1
- Heading outline matches search intent
- Canonical, hreflang, pagination if present
- Indexable (200, no noindex)
- Image alts that describe
- Internal links to related money pages
- Schema types appropriate to the template

## Output

Page snapshot table, issues by severity, exact rewritten title and meta if weak, and the 5 highest-leverage edits.
