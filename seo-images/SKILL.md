# Image SEO

## Checks

- Alt text that describes, not dumps keywords
- Descriptive file names
- Dimensions and lazy loading
- Image sitemap if present
- Compression and format

## Output

- Issues by severity
- Rewritten alt text for weak images
- Recommended file name changes
