# MM Rank aeo

Packaging on a page that already deserves a cite. Not a mention-buying plan.

Submodes — snapshot, audit, plan, fix. Default audit if the user named a domain, fix if they named a page.

## Do

1. Check robots for GPTBot, ClaudeBot, PerplexityBot, Google-Extended
2. Score 3-8 passages on direct answer, source, number-or-entity, no contradiction
3. Rewrite the weakest high-value passage so 2-4 sentences can be lifted
4. Draft llms.txt only if missing and the brand wants a map
5. Quote the exact passage that should be citable

Do not promise an answer engine will name the brand.
